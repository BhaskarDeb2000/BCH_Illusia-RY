# **Sprint Progress Report**

**Sprint Number:** 2  
**Sprint Duration:** April 14, 2025 to April 25, 2025

## **Overview**

The primary objective of this sprint was to implement the booking system, allowing users to book storage units through the platform. The focus was on creating a seamless user experience and integrating the booking functionality with the backend.

## **Completed Tasks**

* Task 1: Designed and implemented the booking system UI. Outcome: A user-friendly interface for booking storage units was created.
* Task 2: Developed backend APIs for handling bookings. Outcome: APIs were successfully integrated with the frontend.
* Task 3: Integrated Supabase for managing booking data. Outcome: Booking data is now securely stored and managed.

## **Tasks In Progress**

* Task 1: Testing and debugging the booking system. Current status: In progress, with minor bugs identified. Expected completion date: April 27, 2025.  
* Task 2: Writing documentation for the booking system. Current status: Drafting in progress. Expected completion date: April 28, 2025.

## **Blockers and Issues**

* Issue 1: API response delays during peak usage. Impact: Slower booking process for users. Proposed resolution: Optimize database queries and implement caching.
* Issue 2: Minor UI inconsistencies across devices. Impact: Suboptimal user experience. Proposed resolution: Conduct cross-device testing and fix identified issues.
